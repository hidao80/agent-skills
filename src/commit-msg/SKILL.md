# commit-msgスキルの詳細

現在ステージングされているファイル全体の修正内容から、簡潔なコミットメッセージを提案せよ。メッセージの先頭には、gitmojiによる文字コード形式（例：`:sparkles:`）で書いた適切なgitmojiタグを置け。

## 使用言語のルール

README.mdのコマンドやインストール手順などを除く説明文に最も多く使われている言語をコミットメッセージの言語として使用せよ。ただし、コマンド引数としてlocaleの指定がある場合は、指定された言語を使用せよ。

例） `/commit-msg ja`や`/commit-msg 日本語`であれば、コミットメッセージは日本語で作成せよ。

## 最優先事項

このスキルに含まれているルールより、`AGENTS.md`などのルールを優先せよ。`AGENTS.md`に含まれていないルールがこのスキルファイルに存在する場合は、部分的にこのスキルのルールを使用せよ。
