# web-security-auditスキルの詳細

リポジトリのセキュリティを包括的に調査し、ユーザーが気付いていない意図しない外部通信やデータ保持がないかを確認せよ。

## 参照ファイル

以下を読んでから実行せよ。

- `references/checklist.md`：検索パターン、チェックリスト、リスク評価マトリックス、よくある誤検知パターン
- `references/report-format.md`：報告テンプレート

## 調査項目

1. 外部通信のチェック
2. データの永続化と保存
3. サードパーティライブラリ
4. PWA/Service Worker
5. その他のセキュリティリスク

## 実行手順

### ステップ1：コードベースの探索

TaskツールでExploreエージェントを使用して、以下を調査せよ：

```
- 外部通信関連コードの検索
- データ保存関連APIの使用状況
- package.jsonの依存関係分析
- セキュリティリスクパターンの検出
```

### ステップ2：パターン検索

Grepツールを使用して、`references/checklist.md`のパターンを検索せよ

### ステップ3：ファイルの詳細分析

Readツールで検出されたファイルを読み、文脈を確認せよ：

- 実際の使用目的
- ユーザー入力の取り扱い
- セキュリティ対策の実装状況
- 潜在的なリスクの評価

### ステップ4：レポートの作成

`references/report-format.md`の形式でレポートを作成せよ。

## ベストプラクティス

1. **段階的な調査**：まず広く検索し、その後詳細な分析を行え
2. **文脈の重視**：判断を下す前にコードの意図を理解せよ
3. **誤検知の排除**：安全な使い方と危険な使い方を区別せよ
4. **具体的な引用**：ファイル名と行番号を含めよ
5. **推奨事項の提示**：問題点だけでなく解決策を示せ

## 注意事項

- このスキルは静的解析を行う。実行時の挙動は別途検証する必要がある。
- サードパーティライブラリの内部コードは完全には分析されない。
- 誤検知の可能性があるため、最終的な判断は人間に委ねよ。
