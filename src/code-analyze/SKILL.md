# code-analyzeスキルの詳細

## トレーサビリティと整合性

- **コミットハッシュ**：変更／作成したすべてのファイルの最終行に、現在のコミットハッシュを追記せよ
- **信頼できる情報源（Source of Truth）**：食い違いを検出した場合は、常に実装よりもテストコード（ユニット／統合）を優先せよ
- **検証**：レイヤー間（例：DBとAPI）で食い違いが見つかった場合は「不整合」として記録せよ

## ドキュメントの衛生管理

- **削除整理**：コードベースに存在しなくなったファイル、コンポーネント、機能に関連するエントリー、注記、TODOはすべて完全に削除せよ
- **構成**：`@z-ai/code-analyzed/{CATEGORY_NAME}.md` 配下のディレクトリ構成をOpen Knowledge Formatとして整然と保て
- **フロントマター**：生成するすべての `.md` ファイルには、以下のフロントマターを含めよ：  

    ```frontmatter
    ---
    name: analyzed-{basename}
    description: {目的を1文で記述する。}
    updated_at: {YYYY-MM-DD HH:MM:SS}
    type: analysis
    ---
    ```

## 情報の品質

- **推測時の手順**：提案や推測を行う場合は、簡潔な選択肢を示し、それぞれに推奨度（1〜5）を付けよ。
- **明瞭さ**：すべての図（ER図、フロー図、ユースケース図）にMermaid記法を使用せよ。
- **簡潔さ**：設定ファイルの説明的・定型的な記述は除き、要約または参照のみを記載せよ。

## 対象ファイル

**実行ルール:** 以下の順序で作成または更新せよ。

| 手順 | カテゴリー名 | 対象トピック |
| --- | --- | --- |
| 1 | dependencies | ライブラリ名、バージョン、ライセンス、脆弱性、更新状況。 |
| 2 | infrastructures | CD/CIおよびIaC。 |
| 3 | databases | 接続情報、アーキテクチャ、マイグレーション、カテゴリー別テーブル一覧とその概要、ドメイン領域の概要。 |
| 4 | screens | エントリーポイント、デフォルトルート、URLパターン、コントローラーの継承階層、基底クラス、ビューファイルの規約、基本テンプレートファイル。 |
| 5 | configurations | 主要な設定ファイル、環境別の設定。 |
| 6 | components | アプリケーション構成、独自ベンダー名前空間。 |
| 7 | utilities | グローバルヘルパーのクラス、関数、トレイト。 |
| 8 | performance | パフォーマンスチェック、処理時間・並列プロセス数・ボトルネックの特定。 |
| 9 | known_bugs | セキュリティ上の問題、アーキテクチャ／設計上の問題、互換性の問題、分析の限界に関する注記。 |
| 10 | security | **［必須］**：インジェクション（SQL／XSS／コマンド／パストラバーサル）、シークレットと認証情報の漏えい（ハードコードされたキー、.envのコミット）、認証と認可（保護されていないエンドポイント、バイパス）、**［推奨］**：CORS／セキュリティヘッダー（CSP、HSTS、X-Frame-Optionsなど）、データの露出（APIレスポンス内の機密フィールド、エラー時のスタックトレースなど）、依存関係の脆弱性（ロックファイル内の既知のCVEなど）、**［任意］**：レート制限／ブルートフォース対策、ファイルアップロードの検証（MIMEタイプ、パス制限）、通信の安全性（TLSバージョン、暗号スイート）など。 |
| 11 | test | 提供されるテストの内容。 |
| 12 | development-workflow | 開発ワークフロー。 |
| 13 | overview | プロジェクト概要、技術スタック、リポジトリ構成、リクエストフロー、ドメイン構成、規模、ステップ数（概算行数）、主な機能、開発ワークフロー。 |
| 14 | notes | notes以外のドキュメントに含まれない情報。 |
| 15 | todo | セキュリティ（高優先度）、テスト、データベース、コード品質、インフラストラクチャ、開発者体験、パフォーマンス。 |
| 16 | naming_convention | 変数、テーブル名、カラム名、関数名、クラス名。 |
| 17 | use_cases | ユースケース図。 |
