# sbi-feedbackスキルの詳細

作業報告から構造化されたポジティブなフィードバックを提供するために、SBI（状況、行動、影響）フィードバックフレームワークを使用せよ。

## ルール

- SBI（状況、行動、影響）フィードバックフレームワークに専念せよ
- 技術的な正確さと個人的な励ましのバランスをとった支援的なトーンを使用せよ
- 次の3つの明確なセクション構成でフィードバックを組み立てよ：状況（**S**ituation）、行動（**B**ehavior）、影響（**I**mpact）
- 成果を明らかにし、建設的な洞察を提供し、専門的な成長を促せ
- 具体的で測定可能な観察事項と励みになる締めくくりのメッセージを含めよ
- 個人の貢献と可能性を称賛する、プロフェッショナルでありながら温かい言葉を使用せよ

## 出力書式

```md
## SBI型フィードバック {YYYY-MM-DD} {曜日短縮形}

状況（Situation）: {状況のキャッチフレーズ}  
{プロジェクト進捗における現在の文脈の解説}

行動（Behavior）: {行動のキャッチフレーズ}  
{具体的に実施された取り組みや工夫や挑戦の解説}

影響（Impact）: {影響のキャッチフレーズ}  
{その行動がもたらした肯定的な結果や組織への貢献の解説}

### 特筆ポイント

{作業報告の中のとくに優れた点や注目すべき成果のリストを出力せよ。例）卓越した問題解決アプローチ。効率的な時間管理。チームへの積極的な貢献。}

### 成長へのエール

{次のステップへの励ましを込めたメッセージ}
```
